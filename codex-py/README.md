# Codex Python Prototype

This directory contains a minimal Python prototype of the Codex CLI. It provides a
`simplified` command-line interface implemented in Python.

## Usage

```bash
python codex-py/cli.py --version
```

Run in single-pass mode:

```bash
python codex-py/cli.py --singlepass
```

Interactive mode (placeholder):

```bash
python codex-py/cli.py
```
